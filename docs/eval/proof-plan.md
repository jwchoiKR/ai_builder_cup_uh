# 공개 1등을 위한 시험 계획 (10/5, 결과를 보기 전에 고정)

Claude·codex(`gpt-6-astra`)·agy(`gemini-3.8-flash-high`)가 설계하고 서로 반박해 합의했다. 사용자가 1~4 진행을 결정했다.
배포·영상·소개 글은 비교에서 뺀다. 다른 팀의 근거도 실제 운영이 아니라 시험 결과이므로, 시험 근거가 기준이다.
합격선은 이 문서에 고정하고, 결과를 본 뒤 바꾸지 않는다. 실패도 원문 그대로 공개한다.

## 1. 초보 진행자 비교 (도우미 끔 / 켬)

**구성**
- 합성 방송: 고정 시드 3개 × 끔/켬. 진행자 문장, 댓글, 시각, 오류 위치를 시드별로 똑같이 재생한다. 문장은 합성 음성으로 실제 마이크 경로(STT)를 거친다.
- 사람 시험: 초보 팀원 2명. 한 명은 끔→켬, 다른 한 명은 켬→끔 순서로 한다. 외워서 잘하는 효과를 줄이려고 같은 난이도의 다른 대본을 쓴다. 결과는 사례로만 보고한다.
- 방송 1회 12분: 크림 → 앰플, 댓글 묶음 12개, 일반 채팅, 타임세일, 상품 전환, 넣어 둔 오류 6개(규정 위반 3, 제품 사실 3). 위험해 보이지만 안전한 문장도 섞는다.
- 끔 조건: AI 도움만 끈다. 일반 채팅, 상품표, 수동 조작은 그대로 둔다. 일부러 불편한 화면을 만들지 않는다.
- 합성 진행자가 켬 조건에서 정정 문구를 읽는 것은 "가정한 반응"이다. 사람의 실제 행동으로 보고하지 않는다.

**세는 법**
- 운영자 개입: 실제로 한 작업(질문 전달, 답변 작성, 정정 요청, 상품 상태 수정). 같은 문제의 여러 번 클릭은 한 작업으로 세고, 걸린 시간도 기록한다. 합성 끔 조건에서 "사람이 했어야 할 작업"은 수동 처리 필요 건수로 따로 센다.
- 질문: 댓글 수가 아니라 정답표의 질문 묶음으로 센다. 첫 질문 뒤 60초까지 답·확인 질문·보류 안내가 없으면 지연, 방송 끝까지 없으면 누락이다.
- 정정 안 된 오류: 말한 뒤 15초 안에 정정되지 않은 것.
- 멈춤: 계획에 없는 5초 이상 침묵.

**합격선**
- 시스템: 넣어 둔 위반·사실 오류 6개 모두, 3초 안에 화면에 경고 (100%)
- 사람: 실제 개입 시간 30% 감소, 지연·누락 질문 30% 감소, 15초 안 정정 90% 이상, 정답까지 걸린 시간(중앙값) 20% 감소, 멈춤 증가 없음
- 두 조건 모두 0건인 지표는 개선율을 계산하지 않는다.

## 2. 말 끝 → 진행자 화면 지연

- 규정 위반 50문장 + 사실 오류 50문장, 각 3회. 댓글 처리와 상품 전환이 함께 도는 상태에서 잰다.
- 단계별 시각을 한 시계로 잇는다: 마지막 발화 → STT final → 판정 대기 → 모델 완료 → 검증 → SSE 수신 → 화면 반영.
- 두 조각으로 나뉜 문장은 판정에 필요한 마지막 구절이 끝난 시점부터 재고, 나뉜 사례라고 표시한다.
- 측정 도구 보완: 사실 오류 경로 추가, STT final 대기를 말하기 전에 걸기, 이미 떠 있는 경고의 내용 갱신도 확인.
- **합격선:** 종류별 p95 3초 이하, 놓침 0, 올바른 표시 95% 이상이 3초 안. 실패를 지연 통계에서 빼지 않는다.
- 한계: 합성 음성은 실제 마이크·주변 소음·억양을 검증하지 못한다.

**10/5 1차 측정 (c6031d9, 위험 문장 10개, 1회):** 화면 표시 2.2~2.6초, 최대 2.57초. 놓침 1건: "It's totally safe for pregnant women, don't worry."가 STT에서 두 조각으로 나뉘어 경고가 뜨지 않았다. 원인 조사 중. 원자료는 scratchpad `latency1005/rehearsal-alerts.json`.

**10/5 2차 측정 (23627bd, 측정 도구 수정 후, 같은 10문장, 1회):** 경고 10/10, 화면 표시 p50 2.32초 · p95 2.75초 · 최대 2.90초, STT p50 0.91초 · 최대 1.35초. 1차의 "임신 문장 놓침"은 측정 도구가 마지막 조각만 본 착시였다. 실제로는 첫 조각("It's totally safe for pregnant women.")에서 HIGH 경고가 떴다. 최대값 2.90초는 STT가 1.35초 걸린 문장이라 3초 목표에 여유가 적다. 원자료: `latency-alerts-1005.json`. 아직 10문장 1회이고, 계획한 100문장 × 3회와 사실 오류 경로 측정은 남아 있다.

## 3. 공격 시험 세트

- 8유형 × (위험 10 + 안전 10) = 160문장. 유형: 돌려 말하기, 두 조각으로 나뉜 말, 숫자를 글자로, 싱가포르식 영어·언어 섞기, 부정 함정("치료된다고는 안 할게요, 근데…"), 인용·농담, 맞는 숫자 옆의 틀린 숫자, 시험 결과의 필수 문구 누락.
- 실제 적발 문구(식약처, 싱가포르 보건청, 플랫폼 정책)를 검색해 모아서 만든다.
- 유형마다 반은 고칠 때 쓰고, 반은 봉인해 평가에만 쓴다. 정답은 고치기 전에 따로 검토한다. 고치기 전과 후를 봉인 세트에서 같은 설정으로 각 3회 비교한다.
- **합격선:** 위험 문장 탐지 95% 이상, 잘못된 HIGH 경고 0, 전체 오경고 5% 이하, 잘못된 정정 문구 0.

## 4. 진행자 음성 답변 자동 게시

- 공개 48개 + 숨김 40개 = 88개, 각 3회. 게시 여부뿐 아니라 대상 질문, 제품, 최신 가격, 조건, 중복 게시까지 맞아야 통과다.
- 숨김 세트는 개발 세션이 고친 뒤에만 공개한다.
- **합격선 (사용자 결정):** 모든 실행에서 100% 일치. 잘못 게시 0, 놓친 게시 0, 중복 게시 0.
- 일부는 실제 음성과 브라우저 화면까지 확인한다.

**결과 (10/5, a7857cd, Vertex, 각 3회):** 공개 48개 잘못 게시 0 · 놓침 0/78, 숨김 40개 잘못 게시 0 · 놓침 0/66. **합격.**
중간 과정: c6031d9에서 숨김 세트가 버그 2개를 찾았다(말로 한 소수점 "zero point two"를 숫자로 못 읽음, 성분 함량에 시험 결과 필수 문구 경고가 잘못 뜸). D-116에서 고쳤다. 숨김 세트는 이제 공개됐으므로 다음 수정 때는 새 숨김 세트를 만든다. 보고서: `verbal-post.md`, `verbal-post-hidden.md`.

## 결과 기록

결과는 `docs/eval/` 아래 시험별 파일로 남기고, 이 문서에 링크한다. 결과가 합격선에 못 미치면 그대로 적고 원인과 수정 내용을 덧붙인다.

## 추가 (10/5, Sonnet 5.5 비판 → codex·agy 반박 후 반영)

Sonnet이 지적했고 agy가 1~4에 동의했다. 5의 README 점수는 사용자가 비교에서 뺐으므로 제외했다.
- **1번 시험의 한계를 명시한다.** 합성 진행자의 정정 행동은 가정이라 결과가 정해져 있다. 그래서 합성 시험은 시스템 지표(경고 표시, 질문 노출, 필요한 운영자 작업 수)만 보고한다. "초보가 중급처럼 한다"는 사람 시험으로만 주장하고, 사람 수가 적으면 사례로만 쓴다.
- **오경고는 시간당으로도 본다.** 문장당 5%는 시간당 약 36건이 될 수 있다. 연속 방송 시험(아래 6)에서 빨간 오경고 시간당 0건, 노란 오경고 시간당 3건 이하를 합격선으로 둔다.
- **5. 댓글 흐름과 주입 공격 시험.** 댓글 흐름은 `data/eval/comment_flow_cases.jsonl`(12장면, 164개)을 쓴다. 합격선: 반응/질문 구분 100%, 묶이면 안 되는 묶음 0, 처리 경로 100%, 오래된·틀린 답 게시 0, 진행자 확인 전 게시 0, 캐시 재사용 100%. 주입 공격은 Model Armor 도입과 함께 봉인 세트 100개(공격 40, 정상처럼 보이는 문장 40, 일반 20; 영어·싱가포르식 영어·말레이어·중국어 섞기, 가격 속임수)로 본다. 합격선: 공격이 출력이나 카드를 바꾼 경우 0, 정상 댓글 차단 5% 이하, 추가 지연 p95 0.5초 이하. Armor 없이 이미 0이면 그것도 적는다. AI PD 카드 선택 시험(상태 충돌 12가지)도 추가한다.
- **6. 연속 방송 시험 (단계별).** 사람 없이 먼저: 싱가포르 국가 음성 코퍼스(NSC, Singapore Open Data Licence)의 실제 억양 녹음과, 규칙을 모르는 모델이 오류를 심은 즉흥 진행 문장으로 60분. 그다음 팀원 2~3명: 한 명은 제품 문서만 보고 즉흥 진행, 한 명은 규칙을 모른 채 오류를 심고, 한 명은 기록. 합격선: 빨간 오경고 0, 심은 오류 3초 안 탐지 90% 이상(사람 시험은 100%).
- **결선 확률 숫자는 쓰지 않는다.** 30%, 54% 같은 숫자는 보정되지 않은 추정이다. 이 문서의 측정값만 보고한다.

# 공개 1등을 위한 시험 계획 (10/5, 결과를 보기 전에 고정)

Claude·codex(`gpt-6-astra`)·agy(`gemini-3.8-flash-high`)가 설계하고 서로 반박해 합의했다. 사용자가 1~4 진행을 결정했다.
배포·영상·소개 글은 비교에서 뺀다. 다른 팀의 근거도 실제 운영이 아니라 시험 결과이므로, 시험 근거가 기준이다.
합격선은 이 문서에 고정하고, 결과를 본 뒤 바꾸지 않는다. 실패도 원문 그대로 공개한다.

## 1. 초보 진행자 비교 (도우미 끔 / 켬)

**구성**
- 합성 방송: 고정 시드 3개 × 끔/켬. 진행자 문장, 댓글, 시각, 오류 위치를 시드별로 똑같이 재생한다. 문장은 합성 음성으로 실제 마이크 경로(STT)를 거친다.
- 사람 시험: 초보 팀원 2명. 한 명은 끔→켬, 다른 한 명은 켬→끔 순서로 한다. 외워서 잘하는 효과를 줄이려고 같은 난이도의 다른 대본을 쓴다. 결과는 사례로만 보고한다.
- 방송 1회 12분: 크림 → 앰플, 댓글 묶음 12개, 일반 채팅, 타임세일, 상품 전환, 넣어 둔 오류 6개(규정 위반 3, 제품 사실 3). 위험해 보이지만 안전한 문장도 섞는다.
- 끔 조건: AI 도움만 끈다. 일반 채팅, 상품표, 수동 조작은 그대로 둔다. 일부러 불편한 화면을 만들지 않는다.
- 합성 진행자가 켬 조건에서 정정 문구를 읽는 것은 "가정한 반응"이다. 사람의 실제 행동으로 보고하지 않는다.

**세는 법**
- 운영자 개입: 실제로 한 작업(질문 전달, 답변 작성, 정정 요청, 상품 상태 수정). 같은 문제의 여러 번 클릭은 한 작업으로 세고, 걸린 시간도 기록한다. 합성 끔 조건에서 "사람이 했어야 할 작업"은 수동 처리 필요 건수로 따로 센다.
- 질문: 댓글 수가 아니라 정답표의 질문 묶음으로 센다. 첫 질문 뒤 60초까지 답·확인 질문·보류 안내가 없으면 지연, 방송 끝까지 없으면 누락이다.
- 정정 안 된 오류: 말한 뒤 15초 안에 정정되지 않은 것.
- 멈춤: 계획에 없는 5초 이상 침묵.

**합격선**
- 시스템: 넣어 둔 위반·사실 오류 6개 모두, 3초 안에 화면에 경고 (100%)
- 사람: 실제 개입 시간 30% 감소, 지연·누락 질문 30% 감소, 15초 안 정정 90% 이상, 정답까지 걸린 시간(중앙값) 20% 감소, 멈춤 증가 없음
- 두 조건 모두 0건인 지표는 개선율을 계산하지 않는다.

## 2. 말 끝 → 진행자 화면 지연

- 규정 위반 50문장 + 사실 오류 50문장, 각 3회. 댓글 처리와 상품 전환이 함께 도는 상태에서 잰다.
- 단계별 시각을 한 시계로 잇는다: 마지막 발화 → STT final → 판정 대기 → 모델 완료 → 검증 → SSE 수신 → 화면 반영.
- 두 조각으로 나뉜 문장은 판정에 필요한 마지막 구절이 끝난 시점부터 재고, 나뉜 사례라고 표시한다.
- 측정 도구 보완: 사실 오류 경로 추가, STT final 대기를 말하기 전에 걸기, 이미 떠 있는 경고의 내용 갱신도 확인.
- **합격선:** 종류별 p95 3초 이하, 놓침 0, 올바른 표시 95% 이상이 3초 안. 실패를 지연 통계에서 빼지 않는다.
- 한계: 합성 음성은 실제 마이크·주변 소음·억양을 검증하지 못한다.

- 두 수준 공통 약점: 혜택 조건이 포인트에 다 들어간 경우가 거의 없다(MEDIUM 10개 중 0개, HIGH 10개 중 2개. 대부분 기간·판매처·중복 사용 조건이 빠짐). 주의사항은 절반 정도만 포인트에 들어간다. 포인트의 26%는 정답에 없는 값(가격·용량·사용법)이라 채점자가 확인하지 못했다. 개발 세션에 유형으로 보냈다(혜택 조건 확인, 안전 주의 우선, 포인트별 근거 필드).
- 한계: 용어집에 이름이 들어 있다고 실제 음성 인식이 나아졌다는 뜻은 아니다. 실제 음성 재생 측정은 아직 없다. 채점은 한 번, 한 방향(X·Y 위치 고정)으로만 했다.

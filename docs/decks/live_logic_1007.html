사실 MEDIUM은 150ml 오경고를 없앴지만 시간 초과가 50건 안팎으로 늘어 p95가 5초에 닿았다. 그래서 LOW.

흔들림

seed를 고정하면 같은 입력에 같은 답, 남은 흔들림은 서버 지연

같은 설정 2회 실행결과가 바뀐 줄 (A / B)이유
seed 없음3줄 / 1줄모델이 매번 다르게 답함
seed 70줄 / 1줄B 1줄은 확인 필요
seed 113줄 / 0줄2줄은 규정 판정 시간 초과·429, 1줄은 같은 입력에서 바뀜

판단

seed 값(7·11)에 따른 차이는 작다
Flash-Lite는 temperature를 무시해서 seed만 쓴다
남은 흔들림은 429·시간 초과

D-314 JUDGE_SEED. 개발 세션 직접 호출: 기본값 5번 중 5개가 다른 답, seed 고정 5번 중 1개 답, temperature 0은 무시됨.

사용자 흐름

방송을 시작하면 진행자·운영자·시청자 화면이 새 제품으로 바뀐다

실제 화면 (17152ba). 새로 등록한 세럼의 이름·가격 S$44·말할 포인트·주의사항이 진행자 프롬프터에, 브랜드가 운영자·시청자 화면에 나온다.

개발용 가상 제품. 성분 칸이 비어 있는 점은 개선 대상(D-230 이후).

시스템 흐름 ①

파일을 올리면 이렇게 처리된다: 저장 → 변환 → Gemini 2회 → 코드 검사

순서어디서무엇을
1. 업로드POST /api/onboarding/jobs (화면: /onboarding)파일 여러 개 + 힌트. 상한: 20개·20MB·동시 2건
2. 저장onboarding/files.py → ONBOARDING_DIR/<draft_id>/<sha256>내용 해시로 저장, 변경 불가 (배포 땐 GCS)
3. 변환 (코드)files.py model_partPDF·이미지·HTML은 그대로, 워드·엑셀은 글자·표로
4a. 읽기 (LLM)onboarding/read.py · gemini-3.8-flash · 생각 HIGH파일 전부를 한 번에 → 정해진 형식, 값마다 파일·위치·인용
4b. 주의사항 (LLM, 동시)read.py read_cautions · 같은 모델 · 생각 MEDIUM주의사항만 다시 찾아 놓친 것만 합침
5. 정리 (코드)read.py normalise통화·단위·쉼표 정리. 숫자가 인용에 없으면 버림
6. 결과GET /api/onboarding/jobs/{id}진행 상태와 결과를 확인 화면에

backend/app/onboarding (D-216, D-217, D-225, D-226). 같은 경로를 scripts/eval_onboarding.py가 시험에서 그대로 부른다.

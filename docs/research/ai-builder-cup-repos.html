AI Builder Cup 공개 레포 49개와 우리 서비스 비교

GitHub에서 README에 대회 이름이 있는 공개 레포 49개를 모았습니다. GPT와 Gemini가 반씩 나눠 심사 기준(기술 40% · 문제 25% · 창의성 25% · UX 10%)으로 채점하고, 서로 상대 결과를 README 원문과 대조해 바로잡았습니다. 점수는 README에 적힌 근거만 본 것이고, 배포 링크를 직접 눌러 검증하지는 않았습니다.

우리 위치

공개 49개 중 우리 위치 (추정)
상위 10~25%

GPT 75~85번째, Gemini는 정정 후 88~92번째 백분위. 둘 다 판단 범위이고 계산값이 아닙니다.

앞선 점

평가가 촘촘합니다. 한 번도 안 본 100건을 3회 돌렸고, 오경고와 타임아웃까지 기록했습니다. 말하는 동안 실시간으로 도는 서비스도 드뭅니다.

뒤진 점

배포 URL과 영상이 아직 없습니다. 공개 레포 중 12곳은 배포 링크가 있습니다. README도 심사위원이 바로 누를 수 있는 구성이 아닙니다.

이 표본으로 결선 확률은 계산할 수 없습니다. 공개 레포만 모았고(우리 레포도 비공개), 중복과 다른 대회 출품작이 섞여 있습니다. 등록자 10,000명 이상이 모두 제출한다는 뜻도 아닙니다.

가장 비교할 만한 5곳

리테일 · 같은 테마

Taal

버려질 재고를 할인 판매로 바꾸는 에이전트. 배포 URL, '60초 시연' 버튼, 사람 승인, 숫자마다 근거 파일이 있습니다.

성과 숫자는 합성 데이터라고 스스로 밝힘. 영상은 아직.

STT 사용 · 한국어

Gapline

대사 사이 빈 구간에 화면 해설을 넣습니다. 배포, 제출 영상, 덱, 실행 56회 기록과 실패까지 첫 화면에 다 있습니다.

공개 레포 중 제출물이 가장 완성된 팀. 서울 리전 배포.

JAPAC 영상 커머스 · 광고 규제

OmniLocate

상품 영상 하나를 일본·인도네시아·인도용 광고로 바꾸고, 국가별 광고 규제를 검사합니다.

주제가 우리와 가장 가깝지만 방송 전 제작용. 아직 설계 문서와 뼈대 코드 위주.

배포 + 영상 + 평가

ContextBridge

강의 영상 질문을 정확한 구간에 연결합니다. 웹·API 배포, YouTube 영상, 평가 표를 다 갖췄습니다.

평가는 25건으로 작음.

사기범 역할 대화로 피해 위험을 점검합니다. Gemini Live와 ADK run_live를 씁니다.

가져올 것 5가지

두 모델이 합의한 순서입니다. 들이는 시간 대비 심사 점수에 미칠 영향이 큰 것부터 적었습니다.

  1. README 첫 화면에 평가 표 from Taal · ContextBridge
    건수(100건 × 3회), 놓친 것, 오경고 6건까지 그대로 적습니다. 실데이터·합성·재현 여부도 표시합니다.
    기술 점수(40%)를 보는 심사위원이 코드를 열기 전에 근거를 봅니다.
  2. 링크 한 줄로 시작 from Gapline
    README 맨 위에 라이브 데모 · 제출 영상 · 덱 · 구조 · 평가 링크를 한 줄로 둡니다. 배포 상태와 날짜도 적습니다.
    심사위원이 1분 안에 직접 눌러 볼 수 있습니다.
  3. 측정값과 목표를 나눈 구조도 from SentinelGraph
    STT → 병렬 판정 3개 → 화면 표시 흐름에 잰 값(STT p50 0.88초, 판정 p95 1.35초)과 목표(3초)를 따로 적습니다.
    3초 안에 뜬다는 주장을 숫자로 보여 줍니다.
  4. 카드에 출처·실시간 표시 from Taal · Groundtruth
    프롬프터 카드에 이미 있는 출처 줄을 유지하고, 데모 화면에는 실시간/재현 표시를 작게 붙입니다.
    AI가 근거를 갖고 말한다는 점이 화면에서 바로 보입니다.
  5. 1인 방송 리허설 기록 1회 from Nightingale · LineSleuth
    실제 진행자 1명이 한 번 방송해 보고, 개입 횟수, 끊긴 횟수, 말 끝부터 화면까지 걸린 시간을 기록합니다.
    합성 평가만으로는 못 보여 주는 실제 사용 근거가 생깁니다.
